# コンプライアンス・免責に関する注意点

理学療法士(PT)としての専門性を発信の強みにする一方で、医療系の情報発信には
一般的な情報発信より高い注意義務が伴う。以下は本リポジトリの生成物・運用フローに
組み込むべき前提であり、法律の専門家によるレビューを代替するものではない。
**実際の運用前に、必要に応じて弁護士・所属団体(日本理学療法士協会等)に確認すること。**

## 1. 診断・治療の言い切りを避ける

- 理学療法士法・医師法上、個別の症状に対する「診断」や「治療方針の断定」は
  医師の業務独占領域に触れる可能性がある。
- 記事は常に「一般的な情報提供」の体裁を取り、「気になる場合は医療機関(小児科・
  整形外科等)を受診してください」という受診勧奨で締める。
- 「これで治ります」「異常です」等の断定表現は禁止し、「〜の可能性があります」
  「〜のケースが多いとされています」等の表現に統一する。
- すべての記事末に定型の免責文を入れる(`content/persona.md` 参照)。

## 2. 個別相談・オンライン講座を提供する場合

- 「治療」ではなく「情報提供」「相談」の枠組みであることを利用規約・申込ページに明記する。
- 有償の個別セッションで具体的な運動指導を行う場合、実施内容が実質的に
  「業として行う理学療法」に該当しないか、事前に協会等に確認する。

## 3. 広告・タイアップ・アフィリエイト

- 2023年10月施行のステルスマーケティング規制(景品表示法)により、
  企業から対価を受けて行う投稿には **「広告」「PR」「#PR」等の明示が必須**。
  自主的な感想であっても報酬を受けている場合は同様。
- アフィリエイトリンク(Amazonアソシエイト等)を含む記事にも
  「本記事にはアフィリエイトリンクを含みます」等の開示を入れる。
- 特定商品の効能・効果を保証するような表現(薬機法に抵触しうる表現)は避ける。
  例:「この抱っこ紐で腰痛が治ります」→「腰への負担軽減が期待できる設計です」等に留める。

## 4. 有料コンテンツ・特定商取引法

- note上のメンバーシップ・有料記事・電子書籍等、継続課金や物品・デジタル
  コンテンツ販売を行う場合は特定商取引法に基づく表記(事業者名、連絡先、
  返金条件等)が必要になる場合がある。noteのガイドラインと合わせて確認する。

## 5. 個人情報・子どもの画像

- 自分の子どもの写真・エピソードを載せる場合も、成長後の本人の意思を
  尊重する観点から、顔出しの範囲や具体的すぎる個人情報の記載は
  最小限にすることを推奨。

## 6. このリポジトリの自動化への反映

- `scripts/generate_draft.py` が生成するすべての下書きには、上記の免責文と
  受診勧奨の文言をテンプレートとして必ず含める(手動で削除しない運用を推奨)。
- 生成された下書きは **必ず人間(PT本人)がレビューしてから公開する**
  (`.github/workflows/weekly-draft.yml` がPRとして起票するのはこのため)。
